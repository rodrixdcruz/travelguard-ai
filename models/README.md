# Model Artifacts

Generated by `python -m app.ml.train` (run from `backend/`). Git-ignored —
they are reproducible: training is deterministic (fixed seed), the dataset
regenerates identically, and retraining reproduces the same metrics.

| File | Model | Target |
|---|---|---|
| `safety_rf_v0_1.joblib` | RandomForestRegressor (220 trees) | Contextual Travel Risk Score 0–100 |
| `recommender_gb_v0_1.joblib` | GradientBoostingRegressor | Place preference score 0–100 |

Each `.meta.json` records `model_version`, `training_date`, `features`,
`dataset_type: synthetic`, and the held-out evaluation `metrics`.

If an artifact is missing or fails to load, the API transparently falls back
to the deterministic rule engine and reports `model_used: "rule_based_demo"`
(never pretending the ML model is running).
